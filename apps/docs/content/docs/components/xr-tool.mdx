## Installation

```bash
npx shadcn@latest add @simple-ai/xr-tool
```

The CLI also installs `@simple-ai/tool` (for `toolTitle`) and `@simple-ai/xr-markdown`.

## Usage

The in-world analog of `tool`. Starts collapsed. The header is the readable tool name plus a short input summary. Expand to see Input and Output as plain text.

```tsx
import { XrTool } from "@/components/ui/xr-tool"

export function ToolCall() {
  return (
    <XrTool
      input={{ feature: "hole", diameter_mm: 8 }}
      output={{ ok: true, diameter_mm: 8 }}
      toolName="cad_edit"
    />
  )
}
```
