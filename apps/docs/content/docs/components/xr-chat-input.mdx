## Installation

```bash
npx shadcn@latest add @simple-ai/xr-chat-input
```

The CLI also installs `@simple-ai/xr-button` and `@simple-ai/world-card`.

## Usage

This is the in-world analog of `chat-input`. It is a uikit field, not TipTap. The value is uncontrolled so layout cannot echo `setState`. `onSubmit` receives the trimmed string; the field remounts after send.

```tsx
import { XrChatInput } from "@/components/ui/xr-chat-input"

export function Composer() {
  return (
    <XrChatInput
      onSubmit={(text) => {
        console.log(text)
      }}
      placeholder="Ask in world space"
    />
  )
}
```

Render it inside a uikit root on a `world-card`. Do not put the 2D chat input in WebGL.
