## Installation

```bash
npx shadcn@latest add @simple-ai/vr-message-scroller
```

The CLI also installs `@simple-ai/vr-button` and `@simple-ai/world-card`.

## Usage

The VR analog of shadcn `message-scroller`. It follows new content while you are at the bottom. Scroll away to read; a jump control returns to the live edge. Pass `followKey` as the last message id so a new send starts following again.

```tsx
import { VrMessageScroller } from "@/components/ui/vr-message-scroller"

export function Transcript({
  messages,
}: {
  messages: Array<{ id: string }>
}) {
  return (
    <VrMessageScroller autoScroll followKey={messages.at(-1)?.id}>
      {messages.map((message) => (
        <Row key={message.id} message={message} />
      ))}
    </VrMessageScroller>
  )
}
```

Render it inside a uikit root on a `world-card`. Do not put the 2D message scroller in WebGL.
