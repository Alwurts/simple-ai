## Installation

```bash
npx shadcn@latest add @simple-ai/vr-reasoning
```

## Usage

The VR analog of `reasoning`. A quiet collapsible row. Streaming turns stay open and read “Reasoning...”. Glyphs that the uikit MSDF atlas cannot draw are folded to ASCII.

```tsx
import { VrReasoning } from "@/components/ui/vr-reasoning"

export function Thinking() {
  return (
    <VrReasoning text="The wearer is in a VR session." />
  )
}
```
