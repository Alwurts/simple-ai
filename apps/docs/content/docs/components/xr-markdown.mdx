## Installation

```bash
npx shadcn@latest add @simple-ai/xr-markdown
```

## Usage

The in-world analog of Streamdown. Parses GFM and renders headings, lists, code, and emphasis as uikit text. Missing Inter MSDF glyphs become ASCII via `asciiSafe` so they do not draw as black squares.

```tsx
import { XrMarkdown } from "@/components/ui/xr-markdown"

export function Answer() {
  return (
    <XrMarkdown markdown="Updated the hole to **8 mm**." />
  )
}
```

Do not use Streamdown or HTML inside the card. Import `asciiSafe` for any other string you put in a uikit `Text`.
