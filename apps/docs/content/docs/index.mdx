simple-ai is a registry of agent examples.

[Components](/docs/components) are pieces. [Blocks](/blocks) are a whole screen. [Templates](/templates) are a whole app.

The [chat page](/blocks) is the first block: the thread, the prompt, tools, thinking, and the work folded away so the answer stays readable. Add it with `npx shadcn@latest add @simple-ai/chat-page`.

## Install

```bash
npx shadcn@latest add @simple-ai/chat-page
```

See [Installation](/docs/installation).

Until `@simple-ai` is in the official directory, point `components.json` at the hosted registry:

```json
{
  "registries": {
    "@simple-ai": "https://www.simple-ai.dev/r/{name}.json"
  }
}
```

Or install by URL:

```bash
npx shadcn@latest add https://www.simple-ai.dev/r/chat-page.json
```
