## Prerequisites

Start from a [shadcn/ui](https://ui.shadcn.com) project with the Base UI style. Then add examples. The source is yours.

## CLI

```bash
npx shadcn@latest add @simple-ai/chat-page
```

`chat-page` is the complete chat. The CLI also pulls in the chat input, tool rows, thinking, and the work fold, plus the page layout. It also installs shadcn `sidebar`, `message`, `bubble`, `attachment`, and `message-scroller`.

The page UI lands at `src/features/assistant/page.tsx` (or `features/assistant/page.tsx` if the app has no `src`). Wire a route to it:

```tsx
// Next.js App Router — app/assistant/page.tsx
export { default } from "@/features/assistant/page";
```

```tsx
// TanStack Start — src/routes/assistant.tsx
import { createFileRoute } from "@tanstack/react-router";
import ChatPage from "@/features/assistant/page";

export const Route = createFileRoute("/assistant")({
  component: ChatPage,
});
```

`chat-page` ships a mocked transport, so the gallery and a fresh install work without a model. Point a live transport at your own API when you have one.

## Pieces

If you only want a piece:

```bash
npx shadcn@latest add @simple-ai/chat-input
npx shadcn@latest add @simple-ai/tool
npx shadcn@latest add @simple-ai/worked
```

## In-world chat (Quest / WebXR)

```bash
npx shadcn@latest add @simple-ai/chat-card
```

This example is an in-world chat card for React Three Fiber and WebXR. The page lands at `src/features/assistant-card/page.tsx` (or `features/assistant-card/page.tsx` if the app has no `src`). Wire a route to it the same way as `chat-page`.

The iframe is the desktop view: click the card, drag the handle to move, pinch a corner to resize. On a Quest, Enter VR or AR. Hands (pinch) and controllers (trigger and ray) hit the same `world-card`. The composer is a uikit field in the scene, not the 2D chat input. The transcript is mocked until you point a live transport at your API.

If you only want a piece:

```bash
npx shadcn@latest add @simple-ai/world-card
npx shadcn@latest add @simple-ai/xr-chat-input
npx shadcn@latest add @simple-ai/xr-tool
npx shadcn@latest add @simple-ai/xr-worked
npx shadcn@latest add @simple-ai/xr-reasoning
npx shadcn@latest add @simple-ai/xr-markdown
```

## Hosted registry

If `@simple-ai` is not in the public directory yet, add this to `components.json`:

```json
{
  "registries": {
    "@simple-ai": "https://www.simple-ai.dev/r/{name}.json"
  }
}
```
