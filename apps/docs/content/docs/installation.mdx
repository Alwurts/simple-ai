## Prerequisites

simple-ai is built on top of [shadcn/ui](https://ui.shadcn.com) with the Base UI style. Start adding simple-ai components to your project after that is set up. The source code is yours.

## CLI

```bash
npx shadcn@latest add @simple-ai/chat-input
npx shadcn@latest add @simple-ai/reasoning
npx shadcn@latest add @simple-ai/tool
npx shadcn@latest add @simple-ai/chat-voice-button
npx shadcn@latest add @simple-ai/shell
npx shadcn@latest add @simple-ai/app-shell
npx shadcn@latest add @simple-ai/chat-page
```

`chat-page` depends on `shell`, `chat-input`, `reasoning`, `tool`, and `chat-voice-button`. `app-shell` depends on `shell`. The CLI pulls those in, plus shadcn `sidebar`, `message`, `bubble`, `attachment`, and `message-scroller`.

The page UI lands at `src/features/assistant/page.tsx` (or `features/assistant/page.tsx` if the app has no `src`). Wire a route to it:

```tsx
// Next.js App Router — app/assistant/page.tsx
export { default } from "@/features/assistant/page";
```

```tsx
// TanStack Start — src/routes/assistant.tsx
import { createFileRoute } from "@tanstack/react-router";
import ChatPage from "@/features/assistant/page";

export const Route = createFileRoute("/assistant")({
  component: ChatPage,
});
```

`chat-page` ships a mocked transport, so the gallery and a fresh install work without a model. Add an agent and an API, then point the transport at `/api/chat`. The CLI prints these steps after `shadcn add`.

### Next.js

```bash
npx shadcn@latest add @simple-ai/chat-page
npx shadcn@latest add @simple-ai/weather-agent
npx shadcn@latest add @simple-ai/chat-api-next
```

That writes `src/app/api/chat/route.ts`, `handleAgent`, and the weather `ToolLoopAgent`.

### TanStack Start

```bash
npx shadcn@latest add @simple-ai/chat-page
npx shadcn@latest add @simple-ai/weather-agent
npx shadcn@latest add @simple-ai/agent-handle
```

Add a server route that calls the handle:

```tsx
// src/routes/api/chat.ts
import { createFileRoute } from "@tanstack/react-router";
import { handleAgent } from "@/features/assistant/lib/handle-agent";

export const Route = createFileRoute("/api/chat")({
  server: {
    handlers: {
      POST: ({ request }) => handleAgent(request),
    },
  },
});
```

Or add `@simple-ai/chat-api-hono` and fetch the Hono app from that route instead.

### Hono

```bash
npx shadcn@latest add @simple-ai/chat-page
npx shadcn@latest add @simple-ai/weather-agent
npx shadcn@latest add @simple-ai/chat-api-hono
```

Mount the app (Cloudflare Workers can export it as the default):

```ts
import { chatApp } from "@/features/assistant/lib/chat-hono";

app.route("/", chatApp);
```

### Switch the transport

In `src/features/assistant/lib/chat-transport.ts`:

```ts
import { DefaultChatTransport } from "ai";

export const chatTransport = new DefaultChatTransport({ api: "/api/chat" });
export const initialChatMessages = undefined;
```

Set `AI_GATEWAY_API_KEY` and optionally `AI_MODEL` (defaults to `openai/gpt-4.1-mini`).

More agents are on the [Agents](/agents) page. Each one aliases `assistant` in `src/features/assistant/lib/agent.ts`.

## Hosted registry

If `@simple-ai` is not in the public directory yet, add this to `components.json`:

```json
{
  "registries": {
    "@simple-ai": "https://www.simple-ai.dev/r/{name}.json"
  }
}
```
